# 2.4Ghz-Noise-Generator
I have built a noise generator who generates noise in 2.4ghz and jam it. I just made it for ethical purpose and only use in my devices, I will never use it with anyone else without permission, i know that its illegal. 

Used components,
2x Nrf24l01
1x 0.96" oled
1x Esp32 C3 Zero
1x capacitor
Some jumper wires, and a breadboard.
